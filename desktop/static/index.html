iPhone iOS 16.2 安装与使用指南（纯巨魔 TrollFools & 越狱双支持）

第一步：使用 GitHub Actions 免费云编译 iOS 安装包

将本项目的 vcam-sync-studio 目录推送到你的 GitHub 仓库后，进入仓库 Actions 页面，运行 Build iOS 16.2 Artifacts，即可自动下载产物：

  • VCamSync.tipa —— 手机端同步控制 App（巨魔商店直接安装）
  • VCamHook.dylib —— 纯巨魔 TrollFools 注入用虚拟相机插件
  • VCamTweak-rootless.deb —— 方案 B 越狱环境（Dopamine rootless）安装包

第二步 A：纯巨魔（TrollStore + TrollFools）安装法

  1. 用 iPhone 的 TrollStore（巨魔商店） 安装 VCamSync.tipa。
  2. 打开 TrollFools，选择需要替换相机画面的目标 App，注入 VCamHook.dylib。
  3. 打开 VCamSync，点击「扫码配对」扫描右侧二维码（或点「搜索局域网电脑」），再进入「选择目标 App」勾选刚才注入的 App。

第二步 B：越狱环境（Dopamine / Rootless iOS 16.2）安装法

  1. 用 Sileo / Zebra / Filza 安装 VCamTweak-rootless.deb 并注销（Respring）。
  2. 用 TrollStore 安装 VCamSync.tipa，打开后扫码连接电脑即可自动对手机内相机生效。

第三步：日常拍摄流程

  • 点击拍摄：每次拍照自动输出「照片队列」的当前第 N 张图，完成后自动推进到下一张并同步给电脑端显示。
  • 长按录制：触发录像时实时切换为「视频队列」里的视频画面，松手停止后自动替换为完整视频。
  • 网络提示：若手机搜不到电脑，请保持同一 Wi-Fi 并以管理员运行一次电脑端目录的 allow_firewall_windows.bat 放行 18760 / 18766 端口。
